# Aniko

Неофициальный мультиплатформенный клиент [Anixart](https://anixart.tv) на Kotlin Multiplatform + Compose
Multiplatform: Android, iOS и macOS (Desktop) из единой кодовой базы.

> **Статус: альфа (`v0.0.1`).** Проект в активной разработке, часть функций Anixart ещё не реализована
> (полный список — в [`docs/api/ANIXART_API.md`](docs/api/ANIXART_API.md), раздел «что уже реализовано»).
> Возможны баги, ломающие изменения и потеря локальных данных между версиями.

## Дисклеймер

Aniko — независимый клиент, использующий приватный REST API сервиса Anixart (`api-s.anixsekai.com`), не
задокументированный публично. Проект не аффилирован с Anixart, создан в исследовательских и личных целях.
Поскольку он опирается на реверс-инжиниринг стороннего API, публикация в App Store/Google Play не планируется —
именно поэтому установка на iPhone описана через side-load (см. ниже), а не через официальный магазин.

## Возможности

- Каталог, поиск и рекомендации релизов
- Просмотр карточки релиза (описание, жанры, related-тайтлы, голосование)
- Плеер серий с выбором озвучки/источника (`shared/player`)
- Списки (смотрю / в планах / просмотрено / отложено / брошено), избранное, история просмотра
- Профиль пользователя, авторизация, базовые настройки приватности
- Синхронизация с официальным аккаунтом Anixart (тот же токен, что и в оригинальном приложении)

## Технологии и архитектура

- **Kotlin Multiplatform** — общая бизнес-логика для Android/iOS/Desktop
- **Compose Multiplatform** — общий UI для всех платформ
- **Ktor** — сетевой слой, **kotlinx.serialization** — JSON
- **Koin** — DI, **Multiplatform Settings** — локальное хранилище настроек
- **Coil** — загрузка изображений

Модули:

| Модуль | Назначение |
|---|---|
| `shared:model` | Общие доменные модели |
| `shared:network` | HTTP-клиент, конфигурация API, обработка ошибок |
| `shared:data` | Репозитории, DTO, API-интерфейсы (`shared/data/.../api`) |
| `shared:player` | Проигрыватель видео (embed/iframe-источники) |
| `shared:ui` | Общие компоненты, тема, работа с изображениями |
| `composeApp` | Точка входа платформ (Android/iOS-framework/Desktop), экраны и навигация |

Полное описание используемого API Anixart (эндпоинты, модели, аутентификация) — в
[`docs/api/ANIXART_API.md`](docs/api/ANIXART_API.md).

## Установка готового приложения

### Android

1. Скачайте `.apk` со страницы [Releases](https://github.com/ArkHak/Aniko/releases).
2. На телефоне разрешите установку из неизвестных источников (Настройки → Приложения → Особый доступ →
   Установка неизвестных приложений — для того браузера/файлового менеджера, которым открываете APK).
3. Откройте скачанный `.apk` и установите.

Дополнительный аккаунт разработчика/Google Play для этого не требуется — Android разрешает устанавливать
подписанные любым ключом APK напрямую.

### iOS (iPhone) — установка без платного аккаунта Apple Developer

Важное уточнение терминологии: Apple **всегда** требует, чтобы приложение было подписано каким-либо Apple ID,
даже для side-load — это ограничение iOS, а не желание разработчика. «Без аккаунта разработчика» здесь означает
**без платной подписки Apple Developer Program (99 $/год)** — обойтись можно бесплатным Apple ID, тем же, что
используется для iCloud/App Store. Ограничения бесплатного Apple ID: сертификат подписи действует **7 дней**,
после чего приложение перестаёт открываться и требует переподписи; также есть лимит на число одновременно
подписанных приложений на устройство.

Есть два рабочих способа — выбирайте по ситуации.

#### Способ 1. Прямая установка через Xcode (проще всего, но телефон нужно периодически подключать к Mac)

Требования: Mac с установленным Xcode, бесплатный Apple ID, кабель (или Wi-Fi debugging).

1. Установите [Xcode](https://apps.apple.com/app/xcode/id497799835) из App Store.
2. В Xcode → Settings → Accounts добавьте свой Apple ID (Add Account) — платная подписка не нужна.
3. Склонируйте репозиторий и откройте `iosApp/iosApp.xcodeproj` в Xcode.
4. Откройте `iosApp/Configuration/Config.xcconfig` и укажите `TEAM_ID` — идентификатор вашей персональной
   команды. Найти его: Xcode → Settings → Accounts → выберите свой Apple ID → в списке команд будет
   `<Ваше имя> (Personal Team)`, его Team ID можно посмотреть через «Manage Certificates» или во вкладке
   Signing & Capabilities таргета `iosApp` после выбора команды из выпадающего списка.
   `CODE_SIGN_STYLE` уже выставлен в `Automatic`, Xcode сам выпустит нужный сертификат и профиль.
5. Подключите iPhone к Mac по кабелю (либо один раз подключите кабелем, затем включите Xcode → Window →
   Devices and Simulators → «Connect via network» для дальнейшей работы по Wi-Fi).
6. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика (Developer Mode) →
   включить → перезагрузить телефон (требуется на iOS 16+).
7. В Xcode вверху выберите ваш iPhone как устройство запуска и нажмите ▶ Run. Gradle-сборка общего фреймворка
   запустится автоматически (build phase `embedAndSignAppleFrameworkForXcode`), это может занять несколько минут
   при первой сборке.
8. При первом запуске на iPhone появится ошибка «Untrusted Developer» — зайдите в Настройки → Основные →
   VPN и управление устройством, выберите свой Apple ID/сертификат и нажмите «Доверять».
9. Приложение установлено и работает. Через 7 дней сертификат истечёт («Не удаётся проверить приложение») —
   подключите телефон к Mac и повторите шаг 7, локальные данные приложения при этом не теряются.

#### Способ 2. AltStore / SideStore (side-load без кабеля при каждом запуске)

Подходит, если не хочется каждую неделю физически подключать телефон к Mac. Компьютер (Mac или Windows) всё
равно нужен для первичной установки и периодического автоматического обновления подписи по Wi-Fi.

1. Возьмите готовый неподписанный `.ipa` со страницы [Releases](https://github.com/ArkHak/Aniko/releases)
   (`aniko-v0.0.1-ios-unsigned.ipa`), либо соберите его сами: в Xcode (после настройки `TEAM_ID`, как в
   Способе 1) выберите Product → Archive для реального устройства, затем Distribute App → Development →
   экспортируйте `.ipa`.
2. Установите [AltServer](https://altstore.io/) (или [SideStore](https://sidestore.io/) — более гибкий форк
   для обновления подписи не только по локальной сети) на компьютер и авторизуйтесь тем же бесплатным Apple ID.
3. Через AltServer установите приложение AltStore/SideStore на iPhone (первый раз — по кабелю), затем в
   Настройках iPhone подтвердите доверие разработчику (аналогично шагу 8 выше).
4. В AltStore на iPhone нажмите «+» и выберите собранный `.ipa` — AltStore отправит его на AltServer для
   подписи вашим Apple ID и установит приложение.
5. Пока компьютер с AltServer доступен в той же Wi-Fi сети (или настроен фоновый VPN-триггер обновления),
   AltStore будет продлевать подпись автоматически, не дожидаясь истечения недели вручную.

> Оба способа ограничены политикой Apple для бесплатных Apple ID (7-дневная подпись, лимит одновременных
> App ID) — это системное ограничение iOS, обойти его без платного Apple Developer Program (или джейлбрейка)
> нельзя.

### macOS (Desktop)

Скачайте `aniko-v0.0.1-macos.dmg` со страницы [Releases](https://github.com/ArkHak/Aniko/releases), откройте
и перетащите `Aniko.app` в `Applications`. Приложение не подписано и не нотаризовано Apple — при первом
запуске Gatekeeper заблокирует его; разрешите запуск через Настройки → Конфиденциальность и безопасность →
«Открыть в любом случае» (или соберите `.dmg` из исходников, см. ниже).

## Сборка из исходников

Требования: JDK 17+, Android SDK (для Android-таргета), Xcode (для iOS-таргета, только на macOS).

```bash
# Android — debug APK
./gradlew :composeApp:assembleDebug
# результат: composeApp/build/outputs/apk/debug/composeApp-debug.apk

# Desktop (macOS) — DMG
./gradlew :composeApp:packageDmg

# iOS — открыть в Xcode
open iosApp/iosApp.xcodeproj
```
