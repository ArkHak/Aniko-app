# Баннер для анонса новой версии (TG-пост)

Утверждённый стиль промо-картинки к релизу (впервые — анонс 0.2.0, 2026-09-29).
Генератор: `generate_announce.py` рядом; пример команды — в его docstring.
Зависимости: python3 + Pillow (на машине разработчика — `/opt/homebrew/bin/python3`).

## Стиль

- **Холст** 1280×640 (2:1, формат превью TG).
- **Фон** — диагональный градиент глубокий индиго `#170E3A` (верх-лево) → фиолет `#4A269E`
  (низ-право). Палитра — из темы приложения (`shared/ui/.../theme/Color.kt`):
  акцент `#836DF0` (PrimaryDark), акцент2 `#F75C61` (SecondaryDark).
- **Слева** — иконка Aniko (`docs/icon.png`) 400×400, скругление 92, тонкая белая обводка,
  мягкое фиолетовое свечение за ней (ellipse + GaussianBlur 90).
- **Звёзды** — четырёхлучевые блики, как на иконке: золотые `#FFDE82` и фиолетовые,
  7–8 штук по краям композиции (координаты — константа `STARS` в скрипте).
- **Справа** текстовая колонка (отступ x=590):
  1. Заголовок `Aniko X.Y.Z` — жирный 92px, белый `#F5F3FF`.
  2. Градиентная полоса 560×14 фиолет→коралл — отсылка к фирменному прогресс-бару.
  3. Подзаголовок-гвоздь релиза — жирный 40px (например «Автообновление уже внутри»), ~25 символов.
  4. До 3 буллетов (точка акцентного цвета + текст 34px), ~34 символа каждый — длиннее обрежется.
  5. Чипы платформ `Android` `iOS` `macOS` — контурные пилюли, приглушённый текст `#BEB6E0`.
- **Шрифт** — системный SF (fallback Arial), кириллица обязательна.

## Рецепт для нового релиза

1. Подзаголовок = главная фича версии, буллеты = 2–3 остальных (из первой секции CHANGELOG).
2. Сгенерировать баннер командой из docstring скрипта, результат — в `docs/media/aniko-X.Y.Z-announce.png`.
3. Открыть и проверить глазами: текст не упирается в правый край, звёзды не перекрывают текст.
