# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[SemVer](https://semver.org/lang/ru/). Пока проект в `0.x`, между минорными версиями возможны
ломающие изменения.

## [0.2.1] — 2026-09-29

Патч-релиз: критический фикс запуска воспроизведения и два исправления интерфейса.

### Исправлено
- **Воспроизведение снова запускается**: Anixart начал отдавать опустевший источник (0 эпизодов)
  первым в списке источников озвучки — кнопка «Смотреть» и переключение озвучки в плеере брали
  его вслепую и молча не запускали видео. Пустые источники теперь пропускаются.
- **Android, автообновление**: при сбое системного установщика (несовпадение подписи, нехватка
  памяти) диалог больше не закрывается молча — причина видна в диалоге и в строке настроек;
  отмена установки пользователем ошибкой не считается.
- Экраны настроек и уведомлений больше не «залипают» поверх вкладок: выбор вкладки на нижней
  панели закрывает их; переход «Мои списки» из профиля не создаёт дубликат библиотеки в стеке.

## [0.2.0] — 2026-09-28

Главное — автообновление: начиная с этого релиза Aniko сама проверяет новые версии и устанавливает
их из приложения.

### Добавлено
- **Автообновление из GitHub Releases**: проверка новых версий (автоматически и кнопкой в
  настройках), скачивание с проверкой SHA-256, пропуск неинтересной версии. Android — установка
  поверх через системный установщик, macOS — самозамена из проверенного DMG с откатом, iOS —
  ручная переподпись свежего `.ipa`.
- **Любимая озвучка в ссылке на тайтл**: при отправке ссылки на релиз в неё подставляется ваша
  самая любимая озвучка (`?voice=…`); у получателя в карточке тайтла сразу выбрана эта озвучка
  (без автозапуска плеера), битые параметры молча игнорируются.
- **Учёт региона для лицензионного контента**: блок воспроизведения и note о лицензии теперь
  срабатывают только при подтверждённом регионе RU (определяется по сети, кэш на 24 часа); в
  остальных регионах и при неудачной проверке доступ открыт.

### Изменено
- Полоса прогресса просмотра перерисована — фирменный градиент со свечением.

### Исправлено
- **iOS**: вход в аккаунт больше не теряет сессию, если запись в защищённое хранилище не
  удалась, — сессия сохраняется в памяти до конца запуска.
- **macOS**: вместо падения при отсутствии VLC приложение понятно объясняет, что для
  воспроизведения нужен установленный VLC.
- **Безопасность**: из логов убраны чувствительные данные, сужена область действия токена,
  ужесточены iOS ATS и разрешения Android WebView.

### Важно при обновлении
- **Android**: подпись та же, что у `v0.1.0` — ставится поверх, удалять старую версию не нужно.
- Следующие версии установятся автообновлением из приложения; переход с `v0.1.0` на `v0.2.0` —
  вручную со страницы Releases.
- **macOS**: для воспроизведения видео нужен установленный [VLC](https://www.videolan.org/vlc/).
  Сборка — только для Apple Silicon.
- **iOS**: доставка — только side-load (Xcode, AltStore, SideStore, Sideloadly), подпись
  бесплатного Apple ID действует 7 дней.

## [0.1.0] — 2026-09-25

Первый публичный релиз. С момента `v0.0.2` — переработанный дизайн, полноценный плеер на Desktop,
новые разделы приложения и релизная подпись Android.

### Добавлено
- **Дизайн в духе iOS HIG** одинаково на всех платформах: материал Liquid Glass на нижней панели,
  официальная иконка Aniko и тема, построенная от неё; светлая и тёмная темы с выбором в
  настройках.
- **Desktop-плеер на VLC (vlcj)** с прямым HTTP-резолвом потоков (Kodik, Sibnet, AniLibria):
  полноэкранный режим, выбор и плавное переключение качества, горячие клавиши.
- **Полная desktop-раскладка**: боковая панель, расширенные сетки, карточка тайтла в боковом
  drawer, оконный хром macOS.
- **Плеер**: закреплённые («любимые») озвучки, память озвучки для каждого тайтла, диалог
  «продолжить с места», кнопка −30 сек, жесты яркости и громкости, Picture-in-Picture на Android,
  настройка качества по умолчанию.
- **Новые разделы**: лента, публичные коллекции (только чтение), экран уведомлений с бейджем
  непрочитанных, витрина профиля (обложка, закреплённая секция, акцентный жанр).
- **Каталог**: вкладки «Аниме» / «Дунхуа», панель с поиском и чипами фильтров, ссылки-фильтры,
  значки качества.
- **Комментарии**: написание, голосование, обновление жестом, метка серии.
- **Авторизация**: новый экран входа, регистрация с подтверждением по коду из письма, показ и
  скрытие пароля.
- **Мои списки**: переключатель «список / сетка».
- **Легальные платформы**: для тайтлов, лицензированных в вашей стране, показываются note и ссылки
  на платформы; воспроизведение из приложения блокируется (в том числе через deep link).
- **Версия приложения** в настройках (Android / iOS / macOS).
- **Релизная подпись Android** и минификация R8 — в релизе теперь release-APK вместо debug.
- Документация: двуязычный README с инструкциями установки, юридические замечания, лицензия
  GPL-3.0.

### Изменено
- Обложки грузятся быстрее; повторные переключения озвучки и качества больше не ломают
  воспроизведение.
- Каталог упрощён: единая панель инструментов вместо нескольких рядов фильтров.
- Приложение переведено с устаревших API (`Koin`, state boxes, `ktor IOException`).

### Исправлено
- Чёрный экран и подвисание при выходе из плеера на Desktop.
- Ряд визуальных багов: цвета ячеек серий, отступы шапки, вертикальное центрирование видео, белые
  полосы на недельном графике профиля, невидимый текст в тёмной теме.
- Дублирование `contentDescription` на постерах (доступность), падение списка комментариев на
  нестандартном ответе API, «0 из N» в «Моих списках».

### Важно при обновлении
- **Android**: релизная сборка подписана другим ключом, чем `v0.0.x` (debug). Сначала удалите старую
  версию, затем установите новую.
- **macOS**: для воспроизведения видео нужен установленный [VLC](https://www.videolan.org/vlc/).
  Сборка — только для Apple Silicon.
- **iOS**: доставка — только side-load (Xcode, AltStore, SideStore, Sideloadly), подпись
  бесплатного Apple ID действует 7 дней.
